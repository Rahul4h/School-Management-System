# AI usage

OpenAI Codex was used to scaffold the .NET API, PostgreSQL transaction flow, React interface, Docker setup, integration tests, and documentation. During implementation, Windows PowerShell's default encoding changed Bengali source text into question marks. This was caught by inspecting the generated source and counting replacement characters; affected UI text was rewritten and project files are now saved as UTF-8. The seat-capacity invariant was also reviewed across parallel hold and confirmation transactions, and confirmation now follows the same class-first lock order as hold creation. The environment did not have a running Docker daemon or local .NET SDK, so image builds and automated tests could not be executed here.
